# Sudhanshu Gaikwad Portfolio

Responsive portfolio for network engineering, NOC operations, certifications, and technical projects. Built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Local Development

```sh
npm ci
npm run dev
```

## Production Checks

```sh
npm run lint
npm run build
npm run preview
```

The production output is written to `dist/`. Relative asset paths support GitHub Pages project subpaths. Publish the `dist/` directory using GitHub Pages with GitHub Actions or another static host.

## Before Publishing

- Confirm the profile, contact details, certificate links, and resume are current.
- Replace project links that are still placeholders; placeholder actions are hidden from the site.
- Add the deployed site URL and an absolute social preview image if a custom domain is configured.
